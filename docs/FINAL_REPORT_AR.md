## 2. نتائج الاختبارات

- **الاختبارات الآلية:** 189 ناجحاً و0 فاشلاً، وتنجح أيضاً من نسخة نظيفة من المستودع، والبناء ينجح.
- **فحوص المتصفح:** 26 فحصاً كلها ناجحة، تشمل:
  - العربية والإنجليزية والاتجاهين RTL وLTR، والجوال، والوضع الداكن.
  - الإسناد، وصلاحيات الموظف، والتحديث اللحظي، ولوحة المدير العام، ومفتاح الإيقاف.
- **اختبار الضغط (محلي، عملية واحدة):**
  - 606 طلب Webhook في الثانية، وزمن الاستجابة p95 = ‏147ms.
  - وصلت 3000 رسالة إلى صندوق الوارد خلال 12.8 ثانية، وأُرسل 300 رد عبر الطابور، دون أي خطأ.
  - هذا الاختبار كشف بطئاً في معالجة المهام (نحو 4 أحداث في الثانية) وتم إصلاحه.
- **النسخ الاحتياطي والاستعادة:**
  - تطابق كامل في عدد الصفوف بعد الاستعادة.
  - على النسخة المستعادة عمل تسجيل الدخول وصندوق الوارد وفك تشفير توكنات القنوات، ثم نجح تدوير المفاتيح عليها.

## 3. ما يعمل فعلياً

يعمل الآن (مُختبر محلياً):
- تسجيل الدخول والجلسات والصلاحيات وعزل الشركات.
- لوحة المدير العام والاشتراكات والخطط (مع تقييد أنواع القنوات لكل خطة).
- صندوق الوارد الموحّد والإسناد والرد والمرفقات والقوالب.
- إدارة القنوات والنسخ الاحتياطي وتدوير المفاتيح.

## 4. القنوات التي اختُبرت بحسابات حقيقية

**لا شيء حتى الآن، ولن أدّعي غير ذلك.**
- بيئة العمل هنا تمنع الاتصال بـ api.telegram.org وgraph.facebook.com وapi.render.com.
- لا توجد توكنات أو تطبيق Meta.
- جميع القنوات مختبرة مقابل خوادم محاكاة تطابق واجهات المنصات الرسمية.

## 5. القنوات التي تحتاج موافقات أو بيانات خارجية

- **Telegram:** توكن بوت من ‎@BotFather، ورابط HTTPS عام (بعد النشر). الربط من صفحة «القنوات» فقط.
- **Messenger وInstagram:** حساب Meta Business موثّق وتطبيق Meta، وسياسة خصوصية وشروط استخدام منشورة، ثم مراجعة Meta App Review. التفاصيل في `docs/META_APP_REVIEW.md`.
- **WhatsApp:** حساب WhatsApp Business قائم، وتوكن System User. التسجيل المضمّن يحتاج قرارك بالتقدم لـ Tech Provider.

## 10–11. حساب المدير العام وتغيير كلمة المرور

- لم يُنشأ أي حساب إنتاجي، وليست هناك بيانات دخول افتراضية، عمداً.
- بعد النشر، من نافذة Shell في Render:
  ```bash
  npm run platform:admin -- --email you@example.com --name "اسمك"
  ```
  تُطلب كلمة المرور وقت التنفيذ ولا تُحفظ في أي ملف.
- **لتغيير كلمة المرور:** ادخل إلى `/admin/login`، ثم «حسابي»، ثم «تغيير كلمة المرور». أو من صفحة «نسيت كلمة المرور» إذا كان البريد مفعّلاً.

## 13. ما المطلوب منك (قائمة واحدة)

1. **GitHub:** ثبّت تطبيق Claude GitHub App على المستودع، أو أعد ربط GitHub من https://claude.ai/connect-github، ثم أطلب مني الرفع. أو ارفع بنفسك من ملف الـ bundle:
   ```bash
   git fetch smart-sales-crm-phase3-complete.bundle saas/phase-0-1-clean:saas/phase-0-1-clean
   ```
   ```bash
   git push origin saas/phase-0-1-clean
   ```
2. **Render:** أنشئ حساباً وأضف وسيلة دفع، ثم اختر «New → Blueprint» على هذا الفرع. أدخل `APP_ENCRYPTION_KEYS` و`APP_URL` و`PUBLIC_URL` حسب `docs/DEPLOYMENT.md` §10. لا أستطيع النشر من هذه البيئة لأن الوصول إلى Render محجوب ولا يوجد حساب.
3. **Telegram:** توكن بوت تجريبي بعد النشر، للاختبار الحقيقي من الواجهة.
4. **Meta:** توثيق النشاط التجاري، وتطبيق Meta، وApp ID وApp Secret، وسياسة الخصوصية وشروط الاستخدام (نصوص قانونية يجب أن تعتمدها أنت)، ثم تقديم App Review.
5. **WhatsApp:** حساب WABA ورقم وتوكن System User. والتقدم لـ Tech Provider بقرار منك.
6. **اختياري:** خادم SMTP للبريد، وحاوية S3 للمرفقات بدل القرص.
